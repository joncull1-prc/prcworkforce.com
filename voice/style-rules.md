# Style rules

## Language

UK English only. Common corrections:

maths not math, colour not color, organise not organize, recognise,
analyse, licence (noun) and license (verb), practice (noun) and practise
(verb), programme (not program, unless software), behaviour, favour,
labour, defence, enrolment, fulfil, travelling, cancelled, whilst is
avoided, use while.

## Americanisms to remove

| Remove | Use |
|---|---|
| gotten | got |
| reach out | contact, write to, approach |
| touch base | speak, meet |
| leverage (verb) | use |
| going forward | from here, next |
| deep dive | detailed review |
| circle back | come back to |
| ballpark | rough figure |
| through (dates) | to |
| quarter one | Q1 |
| zip code, fall, vacation, cell phone | postcode, autumn, holiday, mobile |

## Punctuation

- No em dashes. No en dashes used as a dash. Full stop, comma or colon only.
- En dash is permitted in a number range, for example Days 1-30, written as
  a plain hyphen for safety in email.
- Straight quotes, not curly, in anything destined for code or email HTML.
- No exclamation marks.
- Serial comma only where it removes real ambiguity.

## Numbers, dates, money

- Dates: 19 Aug 2026. Never 8/19/26.
- Money: GBP with the pound sign, no decimals on whole amounts.
- Per-seat pricing is always stated per employee per year.
- Percentages as figures: 15%, not fifteen per cent.
- Specific numbers are credibility. Do not round a cited statistic.

## Banned register

No AI or developer jargon in commercial or participant copy: tokens, context,
model, prompt, parameters, hallucination, system limits, endpoint, payload.
Technical terms are allowed only in a clearly separated technical section.

No corporate buzzwords: synergy, holistic, best-in-class, world-class,
game-changing, robust solution, unlock, supercharge, seamless, journey (also
banned above), ecosystem, thought leadership.

No sycophancy: great question, excellent point, good catch, absolutely,
happy to help, I hope this helps.

## Sentence discipline

- Short sentences. One idea each.
- State the mechanism, then the consequence.
- Cut any sentence that only signals tone and carries no information.
- Copy must be paste-ready. No placeholder brackets left in a final draft
  unless the user has to fill them, in which case list them under FLAGS.
